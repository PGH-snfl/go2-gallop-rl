# 2.0m/s·50cm 고정 목표: 속도 추종 완화와 도약 집중

2026-11-12 사용자 지시 적용. [54k 결과](../reports/20261112_gallop_54000_sim2sim_review/README.md)에서 속도 추종은 통과했지만 평균 도약 16.9cm·공중시간 87.5ms에 머물렀다. 속도 판정만 완화해도 PPO 보상은 바뀌지 않으므로 실제 속도 보상과 짧은 도약의 부분 점수도 조정했다.

## 실행

최신 54k 모델을 계승한다. 목표와 모터·위상·관측·행동 계약이 같아 기존 도약과 전진 동작을 이어서 다듬는 출발점으로 사용한다. 이전 50k보다 학습이 유리하다는 비교 실험을 한 것은 아니다. 새 Adam으로 추가 4,000회를 우선 실행하며 50cm 달성 횟수 보장은 없다.

```bash
cd /home/cvr/GH/go2_animalization/gallop

./isaac.sh gallop train \
  --headless --num-envs 256 --iterations 4000 --save-interval 500 \
  --finetune-from runs/isaac/train/unitree_go2_gallop/20261111_182833_2552ed/model_final.pt \
  --config configs/gallop_2mps_50cm_distance_focus.json \
  --video --video-length 500 --video-interval 20000
```

부모가 이미 고정 목표 분기이므로 `--reset-curriculum`을 넣지 않는다. 새 결과는 `runs/isaac/train/unitree_go2_gallop/<새 ID>/`에 저장하며 기존 54k와 모든 부모를 보존한다. 사용자가 학습하며 이번 준비 작업에서 PPO·모방·optimizer 업데이트는 실행하지 않았다.

## 변경한 항목

| 항목 | 이전 | 이번 |
|---|---:|---:|
| 실제 선속도 추종 보상 가중치 | 3 | 1.5 |
| 선속도 Gaussian 보상 오차 척도 std | 0.5m/s | 0.8m/s |
| 목표 방향 전진 보상 가중치 | 2 | 1 |
| 전진 보상의 속도 오차 척도 | 명령의 25% | 명령의 40% |
| episode 속도 RMSE 성공 상한 | max(명령×25%, 0.15) | max(명령×40%, 0.30) |
| 도약거리 보상 가중치 | 8 | 24 |
| 미달 도약 부분 점수 | 0.75×거리비×시간비 | 0.5×(거리비×시간비)² |
| 착지 보너스 | 안정 회복 품질 | 안정 회복 품질×거리비×시간비 |
| 상승 준비 보상 가중치 | 2 | 4 |
| 실제 이륙 보상 가중치 | 0.5 | 2 |
| 공중 발 이격 보상 가중치 | 2 | 3 |

2m/s에서 속도 RMSE 상한은 0.5→0.8m/s다. 이것은 episode RMSE 기준이며 순간 속도를 특정 구간으로 제한하거나 목표를 무작위로 바꾸는 설정이 아니다. 실제 선속도 보상은 기존 planar Gaussian 함수를 사용하므로 xy 오차 척도가 함께 넓어진다. 별도 횡속도 RMSE 0.15m/s·yaw 각속도 RMSE 0.3rad/s 기준, 목표 방향/heading 보상은 유지한다. 정지와 후진에는 전진 점수를 주지 않는다.

## 도약 점수의 의미

거리비는 `clamp(실제 공중 전진거리/0.50m, 0, 1)`, 시간비는 `clamp(실제 공중시간/0.24s, 0, 1)`이다. 50cm와 0.24초를 둘 다 넘으면 완전 점수 1, 미달이면 위의 부분 점수다. 거리가 짧은 도약을 여러 번 해도 한 기준 주기에서 최대 점수를 중복 지급하지 않는다. 초기 낙하·후진·앞다리 미참여를 보상하는 조건으로 바꾸지 않았다.

| 실제 거리·공중시간 | 기존 거리 점수×가중치 | 이번 거리 점수×가중치 |
|---|---:|---:|
| 17cm·90ms | 0.765 | 0.195 |
| 40cm·200ms | 4.000 | 5.333 |
| 50cm·250ms | 8.000 | 24.000 |

표는 거리 점수의 원래 예산이며 최종 지급에는 기존 앞다리 자격·이륙 조건·안정 회복·품질·종료 취소가 적용된다. 거리 보상은 안정 회복 이후 지급한다. 착지 보너스만 거리·시간 진행도에 비례해 줄이고, 거리 보상에 같은 진행도를 또 곱하지 않는다. 안정 착지 횟수 집계도 바꾸지 않는다. 목표 이상 거리는 점수가 포화되며 50cm를 정확히 넘지 말라는 최적화는 아니다.

## 유지한 사항과 한계

목표속도 2.0m/s·최소 실제 공중 전진거리 50cm·최소 공중시간 0.24초 고정, 승급·회귀 없음. 기준 주기 0.60초·참조 공중창 0.30초, 이륙 수직속도 shaping 기준 1.4m/s, 착지/균형/발폭/발높이 보호는 유지한다. 일반보행 1m/s로 출발하는 teacher와 전환 조건, 관절 각도·목표 변화율·공식 실제 속도/effort 비용 및 지속 초과 종료도 유지한다. 부모 std 0.16을 계승하므로 같은 0.16 목표의 500회 탐색 관리가 추가로 noise를 키우지 않는다.

이번 수정은 도약 목표를 향한 학습 목적 조정이다. 54k에서 발견한 짧은 실제 관절속도 초과, 공식 물성 MuJoCo의 공통 teacher 출발 실패, export/DDS 연결 문제를 해결했다고 주장하지 않는다. 실제 50cm 학습 성능과 새 정책의 심투심은 사용자의 학습 완료 후 별도로 평가해야 한다. 검증 근거는 [준비 보고서](../reports/20261112_gallop_distance_focus_setup/README.md)에 기록한다.
