속도3과 거리80은 성공 후 도달하는 상한만 바꾼 것이 아니라 **새 학생 갤롭 구간의 활성 목표**다. 정지→동결1m/s 보행→4초 안정 혼합 후3m/s 목표를 추종한다. 관측된 불안정성이 있으면 기존대로 혼합 진행을 멈추므로 실제 로봇 속도가 즉시3이 된다는 뜻은 아니다.

도약거리는 네 발이 모두 이륙한 시점부터 첫 발 재접촉까지 몸체가 이동한 거리를 이륙 방향으로 투영해5ms 간격으로 측정한다. 전체 보행 주기 이동거리와 구분한다.

3m/s에서80cm를 공중 이동하려면 일정한 수평 속도 가정에서 약0.267초가 필요하다. 기존 약0.078초의 비행 구간에80cm만 지정하면 참조 속도·시간과 충돌한다. 따라서 참조 touchdown을 `[FL .14, FR .28, RL 0, RR .07]`, duty를 `[.28,.22,.28,.28]`로 압축하고 주기를0.60초로 늘렸다. 각 발의 지지 구간을 앞 절반에 배치해 뒤 절반0.30초를 공중 구간으로 확보한다. 이때 참조 수평 이동은0.90m다. 개별 착지 순서를 엄격한 성공 조건으로 요구하지 않는 기존 설정은 유지한다.

이륙·착지 높이가 같다는 탄도 근사에서80cm에 필요한 수직 이륙속도는 약1.31m/s·정점 상승은 약8.7cm다. 참조0.30초 비행은 약1.47m/s·상승11.0cm에 해당한다. 이는 **시간 설정의 규모를 확인하는 계산**이며 실제 Go2의 관절 토크·접촉·공력·다리 도달범위나80cm 달성을 검증한 것은 아니다.

## 이륙·착지 및 안정성 변경

| 항목 | 이전 | 새 설정 |
|---|---:|---:|
| 이륙 준비 구간 | 80ms | 100ms |
| 이륙 수직속도 보상 기준 | 0.4m/s | 1.5m/s |
| 착지 안정 회복 확인 | 80ms | 120ms |
| 착지 하강속도 보상·자격 기준 | 1.2m/s | 1.8m/s |
| 안정 착지 보상 | 4 | 6 |
| 비행 균형 비용 | 3 | 5 |
| 착지 충격·미끄러짐 비용 | 2.5 | 4 |
| yaw 각 오차 비용 | 2 | 4 |
| yaw 회전 감쇠 비용 | 1 | 2 |
| roll/pitch 안정 보상 | 3 | 5 |
| 목표 방향 전진 보상 | 2 | 3 |
| 앞/뒤 발 간격 보상 합계 | 7 | 8 |
| 발 높이 초과 비용 | 3.5 | 4 |

기존 하강속도 기준1.2m/s는 같은 높이로 돌아오는 긴 비행의 예상1.31~1.47m/s와 충돌한다. 그래서 이 **보상 판정의 속도 기준**을1.8m/s로 조정하고, 대신 회복 확인을 늘리며 충격·균형 비용을 강화했다. 착지 힘 상한3배 체중, 자세·각속도·발 미끄러짐 조건은 유지한다. 단순히 이륙하거나 멀리 날기만 하면 점수를 확정하지 않고 기존대로 안정 회복 뒤 거리 보상을 지급한다. 재이륙·불안정 착지는 보상을 취소한다.

발 간격과 높이 가중치는 기존 사용자 선호에 맞춰 약14%만 증가시켰다. 목표 발폭26.98cm, 성공 폭24~30cm·유지율80%, 앞발16cm·뒷발10cm 높이 비용 기준을 유지한다. 발 높이 기준은 보상과 성공 판정에 사용되며 하드 위치 제한은 아니다.

## 유지한 제어와 성공 조건

모터 모델·토크/속도 한계, 물리 관절 범위 중앙90%·목표각 중앙81%, hip6·thigh/calf16rad/s, 실제 관절 초과 감시를 유지한다. 전체 필터 개입률 허용100%도 유지해 높은 개입 빈도 자체로 실패하지 않는다. 보정량 비용8과 별도의 원시 요청각 초과율10% 조건도 유지한다.

전진 추종·앞다리 참여·공중기 포함 주기60%, 몸체 자세·앞뒤 폭 유지80%, 안정 착지80% 등 나머지 성공 조건을 유지한다. 도약거리 성공 판정도80cm 기준을 사용한다. 속도와 거리 목표가 고정됐으므로 성공률이 낮더라도 목표가2.5m/s·14cm로 되돌아가지는 않는다.
