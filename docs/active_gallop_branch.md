## 이하: 28k 복귀 당시의 과거 기록

2026-11-05 사용자 요청으로 일반보행에서 다시 시작한 v5 분기를 별도 보관하고, 원래 갤롭 분기의 마지막 완료 모델을 작업 기준으로 선택했다. 학습이나 모델 변환은 실행하지 않았다.

**준비된 추가학습:** [필터 개입률 승급 제한 해제·학습 명령](gallop_guarded_filter_free.md). 부모는 아래28k 모델이며 새 설정 `configs/gallop_guarded_filter_free.json`에서 개입 허용률만35→100%로 풀었다. 추가2,000회 완료 시30k이며, 아직 이 추가학습은 실행하지 않았다. 아래 설정 표는 이미 완료된28k 모델 자체의 설정이다.

## 원래 모델에 남았던 문제

당시 [28,000회 결과 보고서](../reports/20261103_gallop_guarded_stability_review/README.md)와 저장된 30초 플레이 기준이다. 실제 속도는2.455m/s였고 낙상0, 공중기와 앞다리 참여 조건은 통과했다. 엄밀한 동물 갤롭 분류를 확정한 것은 아니다.

| 남은 문제 | 측정값 | 의미 |
|---|---:|---|
| 제한 전 요청각의 물리 범위 초과 | 6.32% | 정책이 그대로 실행하기 어려운 목표각을 반복 요청 |
| 전체 관절 필터 개입 | 50.89%, 허용35% 초과 | 목표각 여유폭·변화율 필터에 자주 의존 |
| 변화 속도 제한 개입 | 42.23% | 전체 필터와 중복되는 비율이며 더하지 않음 |
| 앞발 지지폭24~30cm 유지 | 64.10%, 목표80% 미달 | 앞발 간격 안정성이 부족 |
| 안정 착지 | 35/53, 66.04%, 목표80% 미달 | 도약 뒤 안정 회복이 충분하지 않음 |
| 앞발 최대높이 | FL23.83cm, 비용 기준16cm | 높이 패널티에도 왼앞발을 높이 듦 |
| 도약거리 | 평균17.51cm, 최대20.72cm | 활성14cm 기준은 통과하지만 최종22cm 미달 |

필터가 제한한 실행 목표각은 각도·변화율 범위를 지켰다. 저장된 실제 관절각도 원래 기계 범위는 벗어나지 않았다. 추가로 좁힌 물리 범위에서는 최대0.003532rad, 약0.202도 초과가 있었지만 실제 감시 허용0.01rad 이내였다. 따라서 요청각 초과와 실제 기계 범위 이탈을 구분한다.

전체 성공이0이라 속도·거리 승급은 없었고 실제 학습은2.5m/s·14cm에 머물렀다. 설정의 최종 목표3m/s·22cm를 달성한 모델로 표현하지 않는다. 다음 해결 대상은 높은 필터 의존, 앞발 간격과 높이, 착지 회복이다. v5의 앞다리 스윙 단계 병목은 별도 분기의 문제다.
