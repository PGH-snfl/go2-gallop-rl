# 2.0m/s·50cm 고정 목표 추가학습

2026-11-11 사용자 지시: 도약거리 50cm 고정, 승급 관련 동작 제거. 설정은 `configs/gallop_2mps_50cm_edu.json`이다. 학습은 사용자가 Isaac Lab에서 실행하며 이번 준비에서 PPO·모방·optimizer 업데이트는 수행하지 않았다.

## 실행

최신 누적 50,000회 모델에서 이어서 추가 4,000회를 실행하는 명령이다. 4,000회는 최초 확인 구간이며 50cm 달성에 필요한 횟수를 보장하지 않는다.

```bash
cd /home/cvr/GH/go2_animalization/gallop

./isaac.sh gallop train \
  --headless --num-envs 256 --iterations 4000 --save-interval 500 \
  --finetune-from runs/isaac/train/unitree_go2_gallop/20261111_155012_ad6309/model_final.pt \
  --reset-curriculum \
  --config configs/gallop_2mps_50cm_edu.json \
  --video --video-length 500 --video-interval 20000
```

`--reset-curriculum`은 부모의 과거 단계 진행도를 버리고 새 고정 목표를 사용한다. actor·critic·초기 noise는 복원하고 Adam은 새로 시작한다. 이후 이번 고정 목표 분기에서 이어갈 때는 해당 새 모델을 지정하고 `--reset-curriculum`을 생략한다. 과거 staged 부모에서 이번 분기로 넘어오는 최초 실행에만 필요한 옵션이다.

저장 위치는 `runs/isaac/train/unitree_go2_gallop/<새 실행 ID>/`다. 체크포인트·manifest·소스·TensorBoard·영상이 실행 폴더에 저장된다. 기존 모델과 실행 폴더는 보존한다. 콘솔은 기존 iteration·주요 학습 통계·시간 표를 유지한다.

## 고정 목표와 남은 제어

- 갤롭 목표 전진속도는 항상 2.0m/s, 속도 표본 범위는 0이다.
- 몸통이 공중에 있는 동안 실제 목표 방향으로 이동한 거리 기준은 항상 0.50m다. 보폭이나 전체 한 주기 전진거리가 아니다.
- 승급·회귀·집단 평가·판정 주기·성공률에 따른 목표 변경은 실행하지 않는다. `FixedGallopGoal`은 결정을 만들지 않으며 이벤트 목록은 비어 있다. 과거 단계 구현은 기존 모델 재현을 위해 남아 있으나 이번 설정에서 사용하지 않는다.
- 정지 안정화→일반보행 1.0m/s→학생 정책 혼합→갤롭의 기존 출발 절차는 유지한다. 따라서 출발 순간부터 2.0m/s인 것은 아니다. 성공률 기반 승급과 별개다.
- 보상과 실패 종료는 유지한다. 성공 여부는 학습 결과를 측정하는 값으로 남고 목표 변경에는 쓰이지 않는다.

기준 주기는 0.60초, 접촉 기준의 공통 공중 구간은 0.30초다. 이는 2.0m/s에서 0.60m의 시간 예산이지만 실제 도약 성능을 보장하지 않는다. 최소 공중시간 0.24초와 실제 거리 0.50m를 각각 확인한다. 이륙 수직속도 shaping 기준은 1.4m/s, 착지 하강속도 기준은 1.65m/s, 준비 0.10초·착지 회복 0.12초다. 도약 보상 가중치 8, 부분 점수 계수 0.75를 사용한다. 앞다리 참여·느슨한 착지 순서·자세와 발 간격 보상은 유지한다.

전신이 떠오르는 높이를 과도한 다리 들기로 벌주지 않도록 발 높이 비용 계산에서 이륙 후 몸체 상승분만 차감한다. 원래 월드 발 높이와 보정량은 로그에 별도로 남긴다. 보정한 앞발 16cm·뒷발 10cm 기준 및 기존 비용 가중치 3.5는 유지한다.

탐색 표준편차는 부모의 관절별 비율을 보존하면서 500회에 걸쳐 평균 약 0.20에서 0.16으로 낮춘다. 완전 rollout 직전에만 변경하며 저장 행동·확률을 수정하지 않는다. std 학습과 entropy 보너스는 끄고 actor·critic PPO는 계속한다. 이것은 승급이 아니며 속도·도약 목표를 바꾸지 않는다.

## 관절·구동 한계

사용한 공개 Go2 URDF의 관절별 상한은 아래와 같다. 근거 원본은 [이전 검증에 보존한 공식 URDF](../reports/20261111_gallop_46000_sim2sim_review/sources/official_go2_description.urdf), [출처 기록](../reports/20261111_gallop_46000_sim2sim_review/sources/official_urdf_provenance.json)에 있다.

| 관절 | 실제 속도 상한 | 적용 effort 상한 | 목표각 변화율 제한 |
|---|---:|---:|---:|
| hip | 30.1rad/s | 23.7Nm | 6rad/s |
| thigh | 30.1rad/s | 23.7Nm | 16rad/s |
| calf | 15.7rad/s | 45.43Nm | 12rad/s |

매 5ms physics 표본에서 실제 관절속도·제한 전 PD 토크·적용 토크를 관측한다. 실제 속도와 제한 전 요구 effort가 상한의 90%를 넘으면 완만한 비용을 주며 가중치는 속도 6, 요구 effort 1, 토크 포화 차이 2다. 실제 속도 또는 적용 토크가 공식 상한을 1e-3 수치 허용차보다 크게 초과하면 그 episode는 성공에서 제외하고, 20ms 지속하면 종료한다. 출발·전환에도 적용한다. 기존 관절각 보호와 모터 제한은 유지하며 실제 관절각·속도 값을 강제로 잘라서 통과시키지 않는다.

이 수치는 공개 Go2 소프트웨어 모델의 경계이며 실기 EDU 개체의 펌웨어·연속 부하 인증값을 뜻하지 않는다. 기존 Go2HV 모터의 토크·속도 곡선을 유지하므로 관절별 실측 구동계를 새로 식별한 것은 아니다.

## 부모 모델 선택과 검증 한계

추천 부모는 최신 50k `20261111_155012_ad6309/model_final.pt`, SHA256 `93394343a7faf50f848e94ec4138c6a354641addb5b0d4e0b65db3f7ad4674a2`다. 46k로 반드시 되돌아가야 할 근거는 없었다. 두 모델 모두 49/64 관측·12 행동 복원이 정확했고, 새 조건의 짧은 동결 평가에서는 성능 우열을 판단할 만큼 학생 구간에 진입하지 못했다. 최신 모델 추천은 호환성과 기존 학습 계승에 따른 선택이며 최적 부모 입증이 아니다.

전체 관련 검사 214개와 마지막 수정 후 집중 검사 25개, 실제 부모별 CPU 복원 21개씩을 통과했다. Isaac에서 두 부모를 각각 16환경×1,500step, 마지막 환경 소스를 16환경×600step 검사했다. 각 부모 56 episode 중 전환 완료는 1회씩이었고 정식 학생 계측은 각각 0.32초/0초로, 50cm 성능 통과가 아니다. 대부분 전환 중 기존 관절 보호로 종료했다. MuJoCo 10step 검사는 신규 계측·어댑터 연결만 확인했다.

기존 MuJoCo 공식 물성 근사의 공통 walking teacher 출발 실패는 해결되지 않았다. 이 보상 변경이나 추가학습만으로 Sim2Sim·실배포 성공을 보장하지 않는다. 상세 로그·부모 비교는 [준비 검증 보고서](../reports/20261111_gallop_2mps_50cm_edu/README.md)에 보관한다.
