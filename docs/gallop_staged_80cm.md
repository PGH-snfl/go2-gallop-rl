# 80cm까지 성공률에 따라 자동 승급하는 갤롭 학습

2026-11-10 구현. 사용자가 학습을 직접 실행한다. 이번 구현 검증에서 PPO·모방 업데이트는 실행하지 않았다. [검증 기록](../reports/20261110_gallop_staged_80cm/README.md)을 참조한다.

## 학습 명령

현재500회 추가학습 모델(누적30,500회)에서 추가15,500회를 실행하면 누적46,000회다.

```bash
cd /home/cvr/GH/go2_animalization/gallop

./isaac.sh gallop train \
  --headless \
  --num-envs 256 \
  --iterations 15500 \
  --save-interval 500 \
  --finetune-from runs/isaac/train/unitree_go2_gallop/20261110_214726_dc4067/model_final.pt \
  --config configs/gallop_staged_80cm.json
```

`configs/gallop_pilot_18cm.json`은 기존 고정18cm 실험용으로 유지한다. 자동 승급에는 위의 새 설정을 사용한다. actor49/critic64·행동12·std를 정확히 이어받고 새 Adam·초기LR1e-4로 시작한다. 모방학습은 없다. 최근 실행 속도로 약4시간이지만 목표 단계에 도달하는 시간이나80cm 성공은 보장하지 않는다.

## 자동 단계

| 단계 | 속도 목표 | 도약거리 목표 | 기준 공중 시간 | 최소 공중 시간 |
|---|---:|---:|---:|---:|
| 0 안정화 | 2.5m/s | 18cm | 78ms | 60ms |
| 1 속도 | 2.75m/s | 18cm | 77ms | 60ms |
| 2 속도 | 3.0m/s | 18cm | 76ms | 60ms |
| 3 거리 | 3.0m/s | 20cm | 76ms | 60ms |
| 4 거리 | 3.0m/s | 30cm | 120ms | 100ms |
| 5 거리 | 3.0m/s | 40cm | 155ms | 130ms |
| 6 거리 | 3.0m/s | 50cm | 190ms | 165ms |
| 7 거리 | 3.0m/s | 65cm | 240ms | 215ms |
| 8 최종 | 3.0m/s | 80cm | 300ms | 260ms |

도약거리는 이륙에서 착지까지 실제 측정한 전진 거리다. 주기 전체 이동 거리와 구분한다.30cm 이후에는 touchdown/duty와 주기를 보간해 공중 창을 늘리고, 준비·회복 시간과 이륙 수직속도·착지 하강속도 보상 기준도 연동한다. 각 환경의 목표와 비행 설정은 reset에서만 바뀌므로 진행 중인 도약의 거리·시간 기준을 변경하지 않는다.

초기 단계는 기존500회 모델과 동일한 기준 궤적이다. 앞서 계획의14cm 전환 진단 단계는 이미 별도 파일럿에서 확인했으므로 자동 학습은18cm 안정화부터 시작한다. 각 단계의 reward 가중치·관절·모터·발 높이 비용 기준은 유지한다.

## 승급과 회귀

- 각 단계 처음60초의 **시뮬레이션 시간**은 적응 구간이다. PPO 학습과 episode 로그는 유지하되 이 구간의 완료 결과는 승급 집계에 넣지 않는다.
- 모든 환경에서 완료된 episode를 하나씩 모은 완전 집단으로 판단한다.256환경이면 최소256개 결과를 기다린다.128환경 미만이면 완전 집단을 누적해 최소128개를 채운다. 같은 환경이 빨리 실패해 여러 번 종료해도 해당 집단에서는 한 번만 집계한다.
- 성공률80% 이상인 완전 평가 구간을2회 연속 달성하면 다음 단계로 승급한다. 시간이나 iteration 수만으로 올리지 않는다.
- 초기 실패도 실패로 집계한다. 이전 단계/이전 세대의 결과는 현재 승급 집계에서 제외하되 원본 로그는 보존한다.
- 성공률50% 미만인 완전 구간이2회 연속 나오면 한 단계 회귀한다.0단계보다 내려가지 않는다.

episode 성공에는 기존 접촉·ROM·공중기 주기율·앞다리 하중/움직임/참여와 관절 감시 조건을 모두 요구한다. 추가로 학생 단독 계측10초 이상, 속도 RMSE≤0.25m/s, yaw RMS≤3°, roll RMS≤5°·pitch RMS≤8°, 앞·뒤 독립 지지폭24~30cm 통과율 각각80% 이상, 안정 착지80% 이상, 해당 거리·공중 시간 충족 도약60% 이상을 요구한다. 최소8주기·10회 착지 평가도 유지한다.

정지→일반보행→갤롭 전환은 파일럿의 개선된 구조를 유지한다. 속도 오차가 혼합 진행을 영구 차단하지 않으며12초 내 학생 단독 제어 진입 실패는 실패 종료다. 엄격한 개별 발 착지 순서는 요구하지 않는다.

**현재500회 모델은 앞발 폭 약61%, 착지 약74%로0단계의 전체 성공 기준에 아직 못 미친다.** 개선될 때까지0단계에 머무는 것이 정상 동작이다.

이 자동 승급은 학습 중 온폴리시 집단 기준이다. 앞서 설계했던 고정 정책4seed·32시작 독립 평가를 매 승급 전에 자동 실행하는 잠금은 포함하지 않는다. 별도 독립 평가와 MuJoCo Sim2Sim·실배포 검증을 통과한 상태는 학습 승급 상태와 구분한다. 이번 검증에서는80cm 실제 도약을 수행하거나 입증하지 않았다.

## 저장·재개·플레이

새 결과는 `runs/isaac/train/unitree_go2_gallop/<실행ID>/`에 저장한다.

- `model_*.pt`, `model_final.pt`: 정기/최종 모델. `manifest.staged_checkpoints`에 각 파일의 SHA·단계·목표·누적 업데이트 수를 기록한다.
- `stage_passed_00.pt`~`stage_passed_08.pt`: 해당 단계의 첫 훈련 통과 판정 시점 정책을 별도 보존한다. 승급이 일어난 수집 구간의 정책이며 같은 파일을 덮어쓰지 않는다.
- `highest_confirmed_stage`: 과거 훈련에서 통과한 최고 단계다. 현재 파일이 그 단계에서 독립 평가를 통과했다는 뜻은 아니다.
- episode의 `success`: 현재 단계 성공. `staged_final_success`: 최종80cm 단계의 성공. 목표 단계에 들어간 것과 실제 성공을 구분한다.

3m/s 단계가 여러 개이므로 속도만으로 재생 단계를 추정하지 않는다. 중간/최종 파일 각각에 저장된 단계와 비행 기준을 복원하며, SHA나 목표가 맞지 않으면 오류로 중단한다.

```bash
# 새 모델 재생: 저장된 단계 고정, 자동 승급 비활성
./isaac.sh gallop play --num-envs 1 --steps 1500 \
  --checkpoint runs/isaac/train/unitree_go2_gallop/<실행ID>/model_final.pt \
  --video --video-length 1500
```

이어 학습할 때는 같은 자동 설정과 원하는 `--finetune-from` 파일을 지정한다. 저장 단계는 복원하고 새 optimizer·새 완전 집단·새60초 적응 구간으로 시작한다. 정밀한 optimizer/RNG 재개와는 구분한다.

콘솔에는 기존 iteration 요약과 함께 드물게 다음처럼 표시된다. 자세한 항목은 TensorBoard와 진행 로그에 남긴다.

```text
stage=0/8 | vx=2.50m/s | leap=18cm | 성공률=0% | cohort=256/256 | hold
stage=0→1/8 | vx=2.75m/s | leap=18cm | 성공률=85% | cohort=256/256 | promote_stage
```

승급 줄의 성공률은 직전 평가 단계의 결과다. 관절 각도·변화율 필터, 실제 관절 감시, 모터 토크·속도 한계와 총 필터 개입 허용100%/별도raw 요청각10% 조건을 유지한다.
