# 추종 가능한 관절 명령으로 재학습하는 조정안

**조정 가능하다.** 현재는 목표각 범위가 이미 강제되므로 같은 각도 제한을 다시 추가하는 것으로 해결되지 않는다. 다음은 구현 가능한 설계안이며, 이번 조사에서는 학습 실행 코드·보상·정책을 수정하지 않았다. [측정 결과](README.md)가 출발 근거다.

## 시작 모델

현재24,000회 최종 모델보다 이번 실행의 **모방 직후 `model_adapted.pt`**를 우선 출발점으로 삼는다. 이 모델은 기존22,000회 동작을 새 출력 구조로 옮겼고 주행 보존 검사도 통과했다. actor49/critic64/action12와 bounded 출력 의미를 유지해 출력 의미를 다시 바꾸는 부담을 줄인다.

이 후보는 PPO0회 모델이다. 기존 실행기의 `--finetune-from`만 바꾸면 아래 안전 제약과 지속 모방이 자동 적용되는 것은 아니므로, 구현 전의 재학습 명령을 제공하지 않는다. 새 필터가 적용되는 환경에서 적응·재학습해야 하며 재생 때 필터만 추가한 결과를 학습 성공으로 취급하지 않는다.

## 실행단에서 각도와 명령 속도를 동시에 강제

기존 soft-limit 안에 관절별 작업 범위를 정하고, 현재 상태에서 허용하는 목표각을 다음처럼 계산한다.

```text
lower = max(작업 최소각, 직전 실행 목표각 − 허용 명령속도 × dt)
upper = min(작업 최대각, 직전 실행 목표각 + 허용 명령속도 × dt)
실행 목표각 = clamp(요청 목표각, lower, upper)
```

직전 목표가 작업 범위 안에서 시작하면 이 교집합은 항상 존재한다. reset/정지/보행/전환에서도 같은 원칙을 사용하고, 일반 보행 teacher의 목표도 같은 실행 제약을 거친다. PPO에는 원래 latent/log probability를 유지하고 previous action은 실제 실행 목표의 기존 단위를 사용한다. 현재49차원 관측에 실제 관절각·속도·직전 실행 목표가 이미 있어 새로운 상태를 숨길 필요가 없다.

이번 오프라인 프로토타입은 기존 soft 범위의 양 끝5% 여유, hip6rad/s·thigh/calf16rad/s를 가정해 저장된1,500 step 명령을 계산했다. 모든 표본에서 작업 각도와 명령 속도 제약을 동시에 만족시킬 수 있었다. 다만 전체 관절 명령의67.68%가 바뀌고 원래 목표와의 RMS 차이가0.365rad여서 큰 제어 변화다. 이 숫자를 검증된 최적 설정으로 취급하거나 그대로 실기용 수치로 고정하지 않는다. 단계별 상한·여유폭은 실제 Isaac 적응 결과로 결정해야 한다.

**각도·명령 속도 제약은 목표에 대한 보장이다.** 실제 관절은 관성과 접촉 하중의 영향을 받는다. 실제 soft 범위까지 유지하려면 관절 속도·제동 여유를 반영한 목표 생성과 상태 기준 검사를 추가해야 한다. 시뮬레이터의 실제 관절 위치를 강제로 잘라 결과를 숨기지 않는다.

## 학습 신호와 동작 보존

| 조정 | 필요한 이유 |
|---|---|
| 제한 전 요청과 실행 목표 차이에 비용 | 필터가 대신 잘라준다는 이유로 계속 극단적인 명령을 내보내지 않게 함. 필터 뒤 값만 평가하면 학습 신호가 사라짐. |
| 새 작업 범위 한계 근접·체류시간 계측 | 범위를 안쪽으로 옮겨 기존 근접 수치가 자동0이 되는 것을 성공으로 오인하지 않게 함. 기존 물리/soft 범위 진단도 유지. |
| 모방 직후 모델을 동결 reference로 유지 | PPO 중에도 같은 상태에서 원래 동작의 실행 가능한 목표를 유지하는 항을 둠. 현재 관측의 reference 목표에도 같은 제약을 적용해 불가능한 명령을 모방하지 않게 함. |
| 실제 soft 초과량·초과 지속시간 비용과 실패 판정 | 현재 실제 RL/RR thigh의 soft 범위 초과를 학습과 성공 판정에 반영. 수치 오차 허용과 실제 실패 시간을 명시. |
| 토크-속도 포화 비용·계측 | 실제 q/qdot와 저장된 PD·토크-속도 한계로 요청 토크와 가용 토크의 차이를 계산. 단순히 모든 추종 오차를0으로 만들면 지지·도약 힘까지 약해질 수 있음. |
| 목표 방향 평가 | body-frame tracking=1만으로 직진 합격을 주장하지 않도록 world yaw 오차와 월드 횡속도/경로를 함께 평가. |

현재의 초과 패널티는 각도 범위 밖 요청을 대상으로 하며 bounded 출력에서는 거의0이다. 새 필터의 속도·작업 범위 초과 요청을 평가하는 항은 별도로 필요하다. 무제한으로 latent 크기만 키워 포화 상태에 머무르는 행동도 진단하고 제어해야 한다.

기존2.2m/s·14cm 출발, 앞다리 참여·큰 관절운동·공중기·발폭·자세·이륙/착지 조건과 느슨한 발 순서는 유지한다. 제약 강도를 조절하는 동안 속도부터 높이지 않는다. 명령을 느리게 만들었다는 이유만으로 관절 ROM이나 도약이 사라지면 조정 실패다.

## 검증 순서

1. 관절 순서·단위·작업 범위·속도 교집합·reset·teacher 혼합·PPO latent 보존을 비학습 검사로 확인한다.
2. 새 제약을 적용한 Isaac 환경에서 reference 적응 및 결정론적 평가를 수행한다. 모방 직후/추가PPO 후 동일 조건·같은 command에서 비교한다.
3. 각도 범위, 실제 soft 초과량, 명령 속도, 필터 개입량, 토크 포화, 추종 오차와 함께 도약·앞다리 참여·ROM·좌우 발폭·목표 방향을 함께 확인한다. 전체 평균만으로 한쪽 무릎의88% 체류를 숨기지 않도록 관절별 결과도 남긴다.
4. 학습 조건과 결정론적 플레이를 분리해 반복 성공을 확인한 다음 MuJoCo Sim2Sim을 수행한다.

검증 전에는 개선된 모션이나 실제 관절 soft 범위의 완전한 보존을 보장하지 않는다. 현재 수행한 것은 저장 명령에 대한 제약 계산 가능성과 재학습 구조의 검토다.
