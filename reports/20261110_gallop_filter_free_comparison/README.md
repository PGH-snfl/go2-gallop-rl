# 필터 승급 제한 해제: 28,000회와 30,000회 비교

**학습 설정의 유효한 차이는 전체 필터 개입률 허용35→100% 하나다.** 28k 가중치와 Gaussian std를 복원해 PPO2,000회를 추가했고 누적30k로 완료했다. 실제 리워드·물리 환경·PPO 설정은 같다. 이번 저장 플레이에서는 도약거리와 안정 착지가 소폭 좋아졌지만 앞발 간격과 yaw각 오차는 악화됐다. 두 플레이 모두 최종 성공은 미달이다.

이번 작업은 저장된 로그와 상태 배열을 비교했다. 새 학습·물리 주행·정책 변경은 수행하지 않았다. [비교 원자료와14개 검증](comparison.json), [원본 해시](input_manifest.json)를 보관했다.

## 대상과 변경

| 항목 | 이전 | 이번 |
|---|---|---|
| 누적 학습 | 28,000회 | 30,000회 |
| 학습 실행 | `20261103_191405_bea09f` | `20261106_000029_077a6f` |
| 플레이 실행 | `20261103_194343_6d76b6` | `20261110_193602_5f8664` |
| 전체 필터 개입 허용 | 35% | 100% |
| 실제 명령 / 도약 기준 | 2.5m/s / 14cm | 동일 |
| 속도 승급 | 0회 | 0회 |

이번 모델의 직접 부모가 이전28k와 일치하는지 체크포인트 해시로 확인했다. actor49·critic64·행동12, 네트워크·PPO·보상 가중치·정지→보행→갤롭 출발, 각도/변화율 실행 필터와 실제 관절 감시를 유지했다. 기존 파일에 없던 v5 기본 필드가 새 설정 파일에 직렬화됐지만 `relearn_enabled=false`라 사용하지 않는다. 기본값을 정규화한 실제 설정 차이는 `guarded_max_intervention` 하나다.

## 실제 플레이 결과

각 모델의 저장된30초 플레이1회씩을 비교했다. 준비 구간을 제외한 학생 갤롭 측정 구간은 이전9.12~30초·1,045표본, 이번9.18~30초·1,042표본이다. 동일한 전진 명령과 환경 설정이지만 다중 seed 평가나 단일 변경의 인과 효과를 확인한 실험은 아니다.

| 측정값 | 이전28k | 이번30k |
|---|---:|---:|
| 평균 전진 속도 | 2.455m/s | 2.496m/s |
| 전진 추종 RMSE | 0.1666m/s | 0.1679m/s |
| 평균 도약거리 | 17.51cm | 18.53cm |
| 최대 도약거리 | 20.72cm | 21.86cm |
| 평균 공중시간 | 76.57ms | 80.09ms |

| 앞발 지지폭24~30cm 유지율 | 64.10% | 51.54% |
| 뒷발 지지폭 유지율 | 98.23% | 98.27% |
| 앞발 최대높이 | 23.83cm | 21.94cm |

평균 속도는 목표에 가까워졌지만 속도 RMSE는 거의 같아 추종 전반이 개선됐다고 단정하지 않는다. 평균 도약은 약1.02cm 늘었고 안정 착지는2회 증가했다. 앞발 간격 유지율은12.56%p 낮아졌고 yaw 오차도 커졌다. 최대 도약21.86cm는 최종22cm 목표에 미달한다.

## 성공 판정과 학습 로그 해석

플레이의 `guarded_limits`와 `stable`은 이전0에서 이번1로 바뀌었다. 이는 필터 허용 기준을 바꾼 효과를 포함하므로 실제 몸체 안정성이 그만큼 개선됐다는 뜻으로 해석하지 않는다. 실제 자세와 착지는 위 물리 측정값으로 비교한다. 여전히 앞발 폭51.54%와 안정 착지69.81%가 각각80% 기준보다 낮다.

학습 마지막1,000회에서5초 이상 계측된 에피소드는 이전4,054개·이번4,058개다. 전체 성공은0개에서3개로 바뀌었지만 이번 성공률도0.074% 수준이라80% 승급 기준에 한참 못 미쳤다. 앞/뒤 폭 조건 통과율은1.68→4.29%, 안정 착지 조건 통과율은1.11→2.05%였다. 이 값은 에피소드 조건 통과율이며 위 플레이의 개별 착지 성공률과 다르다.

두 실행 모두 속도2.5m/s·거리14cm에 머물렀다. 따라서 승급 제한을 풀고 추가학습한 결과이며, 제한 해제만으로 더 빠른 속도에서 학습했다고 표현하지 않는다. 필터 개입률은 계속 진단 지표로 기록한다. 현재 남은 주요 문제는 앞발 간격, 착지 안정성과 방향 오차다.
