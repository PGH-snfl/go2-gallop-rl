# 공식 Go2 관절 한도에 따른 속도·공중 도약거리 계산 — 2026-11-11

**실제 학습 가능한 최고속도·최대 공중 도약거리는 공식 관절 최대값만으로 확정할 수 없다.** 이번 계산은 공식 기구학/관절 경계를 넣은 조건부 접지 속도 검사와 이상적인 공중 탄도 계산이다. 토크·접촉·스윙·자세까지 만족하는 동역학 최적화나 새로운 주행/학습을 수행한 결과가 아니다.

실제 한계값을 모르는 항목은 [calculation.json](calculation.json)의 `exact_trainable_maximum_*`에null로 기록했다. 숫자 하나를 공식 최대치로 오인하지 않도록 아래 가정을 함께 사용한다.

[계산 전체](calculation.json) · [80cm 조건표](ballistic80cm.csv) · [조건부 접지 검사12개](conditional_stance_screens.csv) · [수식 검사](verification.json) · [재현 코드](source/calculate_official_gallop_bounds.py).

## 공식 입력과 확인된 한계

- 공식 [Go2 URDF](https://github.com/unitreerobotics/unitree_ros/blob/master/robots/go2_description/urdf/go2_description.urdf):hip/thigh 속도30.1rad/s·effort23.7Nm,calf 속도15.7rad/s·effort45.43Nm. 위치경계는관절별원본을읽었다.
- 공식 [MuJoCo 모델](https://github.com/unitreerobotics/unitree_mujoco/blob/main/unitree_robots/go2/go2.xml):허벅지·종아리 링크각각0.213m. 무릎을허용최대각−0.83776rad까지폈을때평면내다리뿌리–발중심최대거리약0.38917m다. 다리길이가공중수평도약거리의상한은아니다.
- 공식 [제품표](https://www.unitree.com/go2/)의EDU표기속도0~3.7m/s/MAX약5m/s는기존제품성능표이며우리갤롭정책·공중도약의인증값이아니다.
- 공식 [Go2HV actuator](https://github.com/unitreerobotics/unitree_rl_lab/blob/main/source/unitree_rl_lab/unitree_rl_lab/assets/robots/unitree_actuators.py)의독립모터곡선과URDF의관절별경계는같지않다. 특히현재학습은모든관절에X2=30rad/s를쓰지만URDF calf는15.7이다.
- 제조사EDU시리얼/펌웨어별곡선,관절별동시토크–속도능력,연속/RMS토크·전류·온도및동적발하중한도가없어실제최고성능을확정하지못한다.

이번에도2.5m/s 정책은 MuJoCo에서실제calf20.41rad/s로한도검사를실패했다. 따라서현재우리가공식한도안에서검증한갤롭최고속도·최대거리기록은아직없다. [실제46k검증](../20261111_gallop_46000_sim2sim_review/README.md).

## 접지 다리의 조건부 속도 상한

가정:hip roll0,몸체회전0,다리뿌리–발중심수직거리일정,접지발미끄럼없음,다리가몸체기준앞뒤로대칭인구간을이동. 위치는공식URDF전체범위를사용하며현재81%목표필터를추가로적용하지않았다. 스윙복귀·토크·접촉력·관성·이륙준비는계산에없다. 이가정에서만조건부상한이다.

링크길이l=.213m,무릎각k,thigh각q,발상대수평좌표x,수직거리h:

```text
x ∈ [−v·t_stance/2, +v·t_stance/2]
k = −acos((x²+h²−2l²)/(2l²))
q = atan2(−x,h) − k/2
dk/dx = −x/(l² sin(k))
dq/dx = −h/(x²+h²) − (dk/dx)/2
|joint velocity| = |d(angle)/dx| · v
```

연속구간2001점에서공식위치·속도경계를검사하고수치해로속도경계를찾았다. 임의의공중도약전후를완성한궤적은아니다.

다리뿌리–발중심수직거리28cm에서:

|접촉 시간 가정|각속도 한도100%|각속도 한도의90%만사용|
|---|---:|---:|
|현재18cm참조:T=.39s/최대duty=.45→접지.1755s|2.676m/s|2.571m/s|
|최종80cm참조:T=.60s/최대duty=.28→접지.168s|2.750m/s|2.641m/s|

90%는제안하는설계여유이며Unitree공식정격이아니다.28cm는가정한기하학높이이며실제trunk의지상고28cm와같지않다. 몸체상하운동·앞뒤기울기·비대칭발배치·다른duty나주기를쓰면값이달라진다. 토크나스윙제약은결과를낮출수있다.

높이 민감도,80cm참조의접지시간.168s:

|다리뿌리–발중심수직거리|각속도100%|각속도90%|
|---|---:|---:|
|24cm|2.858m/s|2.730m/s|
|28cm|2.750m/s|2.641m/s|
|32cm|2.557m/s|2.468m/s|

예를들어정고28cm·접지.168s에서3m/s를유지하는경로는무릎최대20.18rad/s가필요해15.7을넘는다. 이것은Go2가3m/s불가능하다는뜻이아니고,그정고/접지/발배치가정에선경로를바꿔야한다는뜻이다.

## 80cm 공중 도약의 필요조건

공중도약거리는한보행주기의전진거리/보폭과구분한다. 무게중심COM이이륙과첫착지에서같은높이이며공중전진속도가일정하고중력만작용한다고가정한다.

```text
t_air = D / v
v_z,takeoff = g·t_air/2
apex_rise = g·t_air²/8
```

|전진속도|80cm에필요한공중시간|수직이륙/착지속도|이륙점대비COM상승|
|---|---:|---:|---:|
|2.0m/s|.400s|1.962m/s|19.62cm|
|2.5m/s|.320s|1.570m/s|12.56cm|
|2.75m/s|.291s|1.427m/s|10.38cm|
|3.0m/s|.267s|1.308m/s|8.72cm|
|3.7m/s|.216s|1.061m/s|5.73cm|

같은80cm에서2.5m/s는3m/s보다수직이륙속도가20%크고이상적수직운동에너지는44%크다. 전진속도를낮추는것이같은공중거리의착지를반드시쉽게만드는것은아니다.

COM상승량은발스윙높이나지면부터의최대몸체높이와다르다. 기존로그는이륙때몸체root의전진방향으로root변위를투영한다. 공중몸체회전/자세변화가있으면COM거리와차이가날수있다. 첫착지의COM높이가다르면표의이륙속도·정점높이도달라진다.

## 현재 시간 설정에서의 거리 예산

공중시간을고정할때의이상적거리D=v·t_air다. 이는현재설정으로계산되는시간예산이며공식기계최대도약거리가아니다.

|공중시간가정|2.5m/s|2.75m/s|3m/s|
|---|---:|---:|---:|
|현재2.5단계의참조.078s|19.5cm|21.45cm|23.4cm|
|80cm최종단계의참조.300s|75cm|82.5cm|90cm|

최종.300s창에서80cm를이동하려면평균공중전진속도약2.667m/s가필요하다.2.5m/s에서80cm를목표로하려면창을최소.320s로늘려야한다. 참조공중시간은실제공중시간을강제하는물리상한이아니다.

현재참조속도/공중시간과관절참조함수도따로계산했다.3m/s·80cm프로필의관절참조피크는thigh17.85rad/s·calf5.82rad/s로속도경계안이다. 하지만이관절참조는접지발이3m/s몸체아래에서미끄럼없이움직이는일관된기구학궤적을보장하지않는다. calf참조는stance/swing경계에서기울기변화도있어가속도·유한토크추종검사가별도로필요하다.

따라서관절참조속도검사와정고접지검사의서로다른결과를실제성능모순으로해석하지않는다. **두검사를합쳐하나의실현가능최대속도/거리라고주장하지않는다.**

## 힘과 착지의 추가 필요조건

평지에서주기적으로수직속도가같은상태로돌아오면한주기의수직충격량은mgT다. 한주기에표의공중기한번만있다고가정하면남은접촉시간의전체평균수직반력은:

```text
average_contact_force / body_weight = T / (T − t_air)
```

80cm·3m/s는T=.60s에서평균1.8BW,2.5m/s는평균2.143BW가필요하다. T=.39s를유지하면각각3.162BW/5.571BW가필요하다. 이는평균값으로최대착지력·개별발힘·관절토크를보장하지않으며다른공중기가있으면더커진다.

가령전체수직반력을전구간3BW이하로제한한다는추가가정에서는3m/s·80cm의수직하강1.308m/s를멈추는데COM감속스트로크가최소4.36cm,2.5m/s에선6.28cm가필요하다. 이식은수직순감속≤(3−1)g를사용한이상적인하한이다. **기존3BW는프로젝트착지평가기준이며공식하중정격이나전구간힘제한이아니다.**

실제각관절토크는자세에따른JᵀF,중력·관성·몸체회전과결합된다.45.43Nm/15.7rad/s를동시에낼수있다고가정하거나최대토크에관절전체가동범위를곱해실제점프가능에너지로사용하지않았다.

## 계산으로 말할 수 있는 결론

1. 공식관절최대값만으로학습가능최고속도·최대공중거리의고유한정답을정할수없다.
2. 단순정고접지검사에서는현재와비슷한시간가정에서약2.5~2.9m/s규모의조건부경계가나오며,이것은동물형몸체상하운동을포함한로봇자체의최고속도가아니다.
3. 80cm는3m/s에서.267s공중기/1.308m/s수직이륙/8.72cm상승이라는명확한필요조건을갖는다. 이것만으로가능또는불가능을확정하지못한다.
4. 최종3m/s·80cm는시간예산에는맞지만관절·힘·스윙·착지를동시에만족하는궤적은아직증명되지않았다.
5. 정확한모델상최대치는관절별모터곡선·질량/관성·마찰·몸체자세범위·보행형식·열/연속부하조건을정한뒤동역학궤적최적화와동결정책검증으로구해야한다. 학습횟수만으로최대치를정할수없다.
