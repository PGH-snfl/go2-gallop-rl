## 결론과 다음 작업

- 현재 정책의 확인된 기능은 **정지 자세 유지**다. 학습의 높은 timeout 비율과 긴 episode length가 곧 명령 추종 보행 성공을 의미하지 않는다.
- 기본 보행 체크포인트 자체의 이동 명령 추종부터 개선/재검증해야 한다. 이 상태를 안정적인 기본 보행이라고 가정해 Gallop 추가 학습으로 바로 넘어가지 않는다.
- 학습 리워드 구성과 초기 저속 command curriculum이 정지에 치우친 해를 허용했을 가능성, 학습의 stochastic action과 평가의 deterministic mean action 차이를 다음에 조사한다. 이번 시험으로 근본 원인을 확정한 것은 아니다.
- 원본 모델·학습 설정·공식 환경 소스를 변경하지 않았다. 추가 학습은 사용자가 요청하기 전에는 실행하지 않는다.
- 최초 평가 프로토타입(`unitree_baseline_nominal_20261027`)은 명령 관측 전달 검증 전 결과라 무효 표시했다. 위 결론은 매 step 검증을 통과한 `nominal_v2`, `randomized`, `immediate` 결과만 사용했다.
