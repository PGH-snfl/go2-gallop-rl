# 성공률 기반80cm 자동 승급 구현 검증 — 2026-11-10

**구현 완료·사용자 학습 실행 대기.** 현재500회 모델에서 추가15,500회를 실행하면 누적46,000회다. 이번 작업에서 PPO/모방 업데이트0회. [학습 명령과 동작](../../docs/gallop_staged_80cm.md), [새 실행 설정](../../configs/gallop_staged_80cm.json).

## 동작

2.5m/s·18cm 안정화 →2.75/18 →3/18 →3/20 →3/30 →3/40 →3/50 →3/65 →3/80의9단계다. 기존 보상 가중치와 관절/모터/필터/앞다리 조건을 유지한다. 비행 창과 이륙·착지 기준은 거리 단계와 함께 보간하며 각 환경의 reset에만 적용한다.

각 단계의 처음60초 시뮬레이션 시간 동안 적응한 뒤, 각 환경에서 완료된 episode를 하나씩 모아 완전 집단을 평가한다. 최소128개·모든환경 참여·80%두구간 연속이면 승급,50%미만두구간이면 한단계 회귀한다. 이전세대와 반복실패의 중복 집계를 막고 원본은 보존한다. 학생 단독10초·절대속도오차·yaw·앞폭/뒷폭/착지/거리/앞다리/실제 관절 gate를 모두 유지한다.

통과 판정 시점의 정책은 `stage_passed_XX.pt`로 별도 보존한다. 정기/최종 모델마다 저장 당시 단계·목표·해시·누적 업데이트 수를 기록하므로 같은3m/s인40cm와80cm를 구분해서 재개·재생한다.80cm 목표에 진입한 상태와 `staged_final_success`/과거최고통과단계를 구분한다.

**검증 범위:** 자동 승급은 학습 중 온폴리시 집단 기준이다. 별도의 고정정책4seed·32시작 독립 평가 잠금은 매 승급 전에 자동 실행하지 않으며 완료정책의 외부 검증으로 남긴다. 원래 계획 JSON에도 이 구분을 반영했다. 이번 연결 검사로80cm 가능성·장기수렴·실기 적합성을 주장하지 않는다.
