## Clipping의 의미와 남은 관절

Clipping은 요청한 관절 목표각이 설정된 허용 범위를 넘으면 경계값으로 제한하는 것이다. 예를 들어 상한 60°인데 80°를 요청하면 실행 목표는 60°가 된다. **22.48%는 공식 구간의 전체 관절 명령 표본 중 제한된 비율**이며, 실제 관절이 물리 한계를 넘었다는 의미는 아니다. 여기서 다루는 것은 PPO의 정책 업데이트 clipping과 별개다.

저장된 실행 action과 학습 USD의 soft-limit으로 재계산해 trace와 일치함을 확인했다. 새 Huber 초과 비용을 부모에게도 동일하게 적용한 비교값은 1.1401→0.2245로 약 80.3% 감소했다. 초과하는 크기는 줄었지만 제한되는 빈도는 여전히 높다. 이 비교 비용이 부모 학습에 실제로 부과됐던 것은 아니다.

## 학습 중 반복 성공률과 속도 승급

학습 적격 episode는 8,304개이고 전체 성공 0개다. 앞발 지지폭 gate를 통과한 학습 episode는 0개, 뒷발은 1,777개다. stable gate도 모두 실패했고, 이 중 7,972개는 기록된 stable의 다른 조건을 만족하면서 clipping으로 실패했다.

최근 200 iteration의 912개 episode에서 raw 추종 통과율은 84.54%로 올라갔다. 충분한 계측을 갖춘 episode의 앞발 폭 유지율 중앙값은 28.25%, 최댓값도 70.89%여서 80%에 못 미쳤다. 평균폭이 목표에 가까워진 것과 매 지지 표본에서 목표폭을 유지하는 것은 다르다. 학습에는 확률적 행동과 환경 변화가 포함되고 저장 플레이는 결정론적 단일 실행이므로, 플레이 앞발 유지율 82.62%를 학습 반복 성공률로 일반화하지 않는다.

속도 판단 48회는 대기 16회 / 유지 32회 / 승급 0회였다. `trained_speed_cap=2.2`, `highest_confirmed_speed=null`이다. 모든 필수 조건의 반복 성공을 요구하는 설계에 따라 현재 단계에 머문 결과다. 다음 검토 대상은 calf 목표각 포화와 학습 중 양발 지지폭 유지, 특히 앞발의 반복 재현성이다. 이번 수집에서는 학습 설계를 변경하지 않았다.
