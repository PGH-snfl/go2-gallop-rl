거리·시간은 몸통의 첫 동시 비접촉 위치→첫 착지 위치를5ms마다 계측한 값이다. 1,000정책step에4,000물리 표본, step마다4표본 증가를 확인했다. 저장 trace는20ms snapshot이므로 [이벤트 CSV](play_flight_events.csv)의 착지·회복 시각은 실제 이벤트 다음 저장 표본 시각이다. 이벤트 counter가 각 표본 사이 최대1씩만 증가하는 것을 확인한 뒤 도약과 안정 착지를 연결했다.

목표 충족 도약의 ID는2·6·31·54다. 각각 약1.70·3.08·11.70·19.64초 저장 표본에 착지가 나타나고, 약80ms 뒤 안정 착지가 확인됐다. 기존의 부분 score 덕분에16cm 미달 도약도 안정 착지하면 거리 보상을 받을 수 있다. 따라서 보상48.37점이나 안정 착지29회를 전부16cm 목표 달성으로 해석하지 않는다.

마지막55번 도약은19.96초 표본에서 착지가 기록됐고,20초 timeout에서는 회복40ms·보관 score0.81738로 진행 중이었다. 필요한80ms를 채우기 전에 episode가 끝났으므로 확정 보상은 없었다. 이1회는 회복 실패24회에 더하지 않는다. 회복 대상이 아닌1회도 실패24회와 구분한다.

기존60ms 공중기 gate는57참조주기 중36주기(63.16%)로60% 기준을 통과했다. 이 값은 충분한 공중기를 포함한 **주기 비율**이다. 저장 접촉 표본에서 실제 공중에 있던 **시간 비율15.46%**와 다른 지표다. 엄밀한 개별 착지 순서의 Gallop 분류 합격은 주장하지 않는다.

## 균형과 남은 문제

| 지표 | 이전3m/s 플레이 | 이번2.5m/s 플레이 |
|---|---:|---:|
| roll RMS | 0.05835rad | **0.04077rad** |
| pitch RMS | 0.05482rad | **0.02551rad** |
| RL / RR hip 주기 ROM | 7.11° / 25.75° | **13.76° / 24.64°** |
| 앞다리 하중 총합 | 43.10% | 44.46% |
| FL / FR 하중 | 20.43% / 22.67% | **13.73% / 30.73%** |
| 목표각 clipping | 16.96% | **15.24%** |
| 실제 완료 도약 | 0회 | **55회** |

roll RMS는 약30% 줄었고, 뒷다리 hip ROM의 좌우 차이도18.64°→10.88°로 줄었다. 반면 **오른쪽 앞다리 하중은 왼쪽의 약2.24배**다. FL/FR 지지시간 비율도32.81%/52.89%로 차이가 남는다. 앞다리 전체 하중·각 발 최소 하중·관절 운동·스윙 참여의 기존 최소 조건은 통과했지만, 이 기준 통과만으로 좌우 균형 완성을 주장하지 않는다.

이번 pair hip 비용은0.01433, pair load 비용0.03078, pair joint 비용0.33146이다. ROM/stance 비용0은 허용폭 이내라는 뜻이다. 속도·참조 duty·패널티 허용폭과 가중치가 함께 바뀌어 비용 자체를 부모와 직접 비교하지 않았다. 위 각도·하중·자세 비교도 동일 명령 대조 실험이 아니므로 특정 보상의 단독 효과로 확정하지 않는다.

**전체 episode의 `stable=false`는 목표각 clipping15.24%가10% 기준을 넘었기 때문이다.** 자세 RMS·자연 생존·다른 모든 episode gate는 이 플레이에서 통과했다. 80ms의 **착지 안정 판정**과 clipping까지 포함하는 **전체 episode 안정 gate**를 구분한다. clipping은 명령한 목표각이 soft-limit에서 잘린 비율이며 실제 관절 한계 위반 측정이 아니다.

공중기는 생겼지만 참조 위상과 정확히 맞지는 않는다. 공중 예정 구간195표본 중91개(46.67%)는 동시 비접촉,104개(53.33%)는 **RR 한 발 지지**였다. 실제 공중 표본56개는 준비 위상에 나타났다. [위상별 통계](play_diagnostics.json)를 보관했다.

회복 실패24회는 코드의 안정 조건을 벗어났다는 기록이며 낙상24회를 뜻하지 않는다. 이번 episode에는 물리 종료가 없었다. 기록된 착지 최대 힘·하강속도는 한계 안이지만, 5ms별 실패 사유 코드와 발 속도 trace가 없어 모든 실패를 각속도·횡속도·미끄러짐·재접촉 등의 특정 원인으로 분리할 수는 없다.
