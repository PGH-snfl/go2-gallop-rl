## 전환 수정과 학습 기록

새 설정에서만 `startup_pose_handover=true`를 켰다. 혼합 진행은 자세·높이·각속도·횡속도 조건으로 진행하고, 속도 명령은 혼합 단계 경과 시간으로 별도 상승한다. 기존 보행 준비의 속도 추종 조건은 유지한다. 혼합에서 속도 오차가 크다는 이유만으로 학생 단독 제어와 도약 계측에 영구히 도달하지 못하는 의존을 분리했다. 출발12초 내 이양 실패는 실패 종료이며20ms 기준-20 보상, timeout이 아니다. 기존 설정에서는 이 옵션을 끈다.
