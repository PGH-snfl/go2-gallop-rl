# 2.5m/s·18cm 짧은 갤롭 검증 학습

2026-11-10 사용자가 이번 짧은 학습과 결과 수집을 에이전트에게 명시적으로 요청했다. 이 실행의 허가이며, 이후 장기학습까지 자동 실행하는 지시는 아니다.

부모는 보존된 v4 30k `20261106_000029_077a6f/model_final.pt`다. 제외한34k와 일반보행 재학습 v5는 사용하지 않는다. 설정은 `configs/gallop_pilot_18cm.json`, 결과는 [짧은 검증 보고서](../reports/20261110_gallop_short_pilot/README.md)에 수집한다.

## 이번에 구현한 범위

- 속도2.5m/s·거리18cm 고정, 기존 주기 약0.39초·공중 창78ms와 기존 보상 가중치 유지. 다른 속도나80cm까지 자동 승급하는 제어기는 이번 범위에 포함되지 않는다.
- `startup_pose_handover=true`일 때 혼합 비율은 자세·높이·각속도·횡속도 조건으로 진행하고, 명령 속도는 혼합 단계 경과 시간으로 별도 상승한다. 혼합 중 속도 오차가 크다는 이유로 학생 단독 제어가 영구히 차단되지 않는다. 일반보행 준비 단계의 속도 추종 조건은 유지한다.
- 출발 후12초까지 학생 단독 제어에 진입하지 못하면 실패 종료한다. timeout으로 처리하지 않는다. 실패 시 보상은 제어주기20ms 기준 -20이다. 자세·실제 관절 감시와 모든 모터·각도·목표각 변화율 한계는 유지한다.
- 기본 옵션은 false이므로 기존 설정의 전환 방식은 유지된다. 이전 정책 재생은 원래 run에 보존된 소스를 사용한다. 새 run에는 수정된 소스를 함께 보관한다.
- 총 필터 개입률 허용100%, 별도 raw 요청각 초과율10%, 앞·뒤 발 높이·간격 및 앞다리 참여 조건 유지. actor/critic/std를 복원하고 새 Adam·초기LR1e-4, 모방학습0이다.

## 실행한 학습

```bash
./isaac.sh gallop train --headless --num-envs 256 --iterations 500 \
  --save-interval 249 \
  --finetune-from runs/isaac/train/unitree_go2_gallop/20261106_000029_077a6f/model_final.pt \
  --config configs/gallop_pilot_18cm.json
```

학습 run은 `runs/isaac/train/unitree_go2_gallop/20261110_214726_dc4067`이다. RSL의0기반 저장 iteration 때문에 `model_249.pt`는 실제250회 업데이트이고, `model_final.pt`는 실제500회 업데이트다. 저장 간격249를 사용한 이유는 정확히250회 지점을 비교하기 위해서다.

평가는 부모0회·250회·500회 정책에 **동일한 새 전환 방식과18cm 목표**를 적용한다. 원래14cm 정책 실행과 새 학습 결과를 서로 다른 조건으로 직접 비교하지 않는다. `scripts/validation/evaluate_gallop_pilot.py`에서 잡음·push·mass/material randomization을 끈 평지8개 시작 조건을 요청하고 첫 episode의 실패도 포함한다. 실제로 동일한 중간 상태를 복제하는 실험은 아니다.

승급 검증과 짧은 방향성 판정은 구분한다. 사전 정의한 판정 기준은 보고서의 `pilot_protocol.json`이다. 학생 단독10초·명목 실패종료0·기존 평균 도약의90% 이상·관절 감시·속도·yaw·앞다리·높이 조건을 유지하면서 앞폭10%p 또는 착지5%p 개선이 있는지 확인한다. 다른 안정성 항목이5%p 넘게 악화되면 개선 후보로 자동 채택하지 않는다.

최종80cm의 실제 달성 가능성과 장기 수렴 시간은 이번 짧은 실험으로 확정하지 않는다.
