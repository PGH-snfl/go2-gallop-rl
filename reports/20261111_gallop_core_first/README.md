발폭/높이 reward와 모든 가중치는 유지한다. 핵심 보행 조건은 시간에 따라 자동 면제하지 않는다. 전진 추종·공중기·앞다리 하중/운동/참여·ROM·단계 거리·생존·raw요청각10%·실제 관절 감시가 필수다. 모터/관절 각도·변화율 필터와 낙상 종료를 그대로 유지했다.

승급은 여전히256환경에서 완전집단·최소128episode·성공80%두 구간 연속이다. 기준을 자동 충족한 것으로 저장하거나 기존46k에 소급 승급을 부여하지 않았다. 새 학습은stage0에서 정상 집계를 시작한다.

최종 단계에선 세부 품질만 미달하고 핵심 보행이 유지되면 `refine_quality`로 최종 목표에서 학습한다. 핵심 보행·큰 자세·방향·착지60% 조건을 만족하는 episode가50% 미만인 집단이2회 연속이면 한 단계 회귀한다. 즉 세부 품질 때문에 최종 단계에서 즉시 후퇴하지 않으며, 핵심 운동 악화는 회귀시킨다.

## 기록 의미

- `success`: 현 단계 진입/승급용 성공. 초기에는 엄격 스타일 성공과 다르다.
- `staged_strict_success`: 기존 엄격 조건 전체 성공.
- `staged_final_success`: final80cm + 엄격 성공.
- `staged_core/pose/heading/landing/details`: 단계별 필수 조건의 통과.
- `staged_regression`, `core_safety_success_rate`: 핵심 보행에 따른 회귀 진단.

manifest에는 `promotion_policy=core_first_v1`과 숫자 문턱을 기록한다. 분석기의 curriculum replay도 새 진단 criteria를 처리하고 strict/final 성공을 별도 집계하도록 갱신했다. 이전 설정/이전 모델의 재생은 저장된 소스를 사용한다.

## 함께 해결한 참조 문제

문헌조사에서 발견한 profile 누락을 수정했다.

1. `update_measurements`의 contact/joint/foot-height reward 참조에 reset-latched phase profile을 전달한다.
2. pair stance 허용차도 각 환경의 실제 profile duty에서 계산한다.
3.0단계 참조의 기존 호환성 및 후반 공중 phase에서 이전 contact mask가 섞이지 않는 것을 검사했다.

새 보상 가중치는 추가하지 않았다. 후반 단계에서 의도한 시간표와 보상 기준이 일치하도록 한 변경이다. 기존 run의 source/config/체크포인트를 수정하지 않았다.

## 과거 학습 로그를 새 문턱으로 재판정

원래46k 학습의184개 **stage0 완전 집단**만 재판정했다. 기존 최고 성공률3.52% 대비 새 기준의 보수적 최고88.67%, 마지막10집단 평균83.95%,80% 이상41집단 및2회 연속 통과 가능 구간을 확인했다.
